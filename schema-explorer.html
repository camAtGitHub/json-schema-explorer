JSON Schema Explorer v6 – Final Edition

Perfect sticky headers · controls scroll away · full data visibility

How to use

  • Paste JSON array or NDJSON into textarea OR upload a file
  • Click Load & Explore to visualize schema
  • Scroll down → controls disappear, breadcrumb sticks at top
  • Click yellow {...} cells to drill down
  • Use breadcrumb navigation to go back up
  • Fit to viewport: equal column widths, no horizontal scroll
  • Min/Max width: control column size limits

Color Legend

  • strings – red text
  • 123 – blue numbers
  • true/false – blue booleans
  • null – purple
  • {...} – yellow background (clickable)
  • [...] – green background
  • - – missing key (gray)
  • Red header – type conflict in column

Type Conflicts

A column has a type conflict when the same key contains different data types across records:

  • Missing keys (absent) do NOT cause conflicts
  • Literal null values DO cause conflicts with other types
  • Empty arrays [], objects {}, or strings "" conflict with different types

Nested Conflict Detection

Auto-scan (enabled for <500 records) recursively scans nested objects:

  • Solid red – Conflict at current level
  • Diagonal stripes – Conflict exists deeper in tree
  • Hover striped headers to see which nested paths have conflicts
  • Configurable scan depth (1-5 levels)
